🚀 How to Run Locally

Clone this repository

git clone https://github.com/<yourusername>/portfolio.git
cd portfolio


Open in browser

start index.html


or simply double-click the index.html file.

(Optional) Customize your own details inside the HTML file.

🎨 Customize It

You can easily edit the following:

Name & Title: Change <h1> and subtitle in the header.

About Section: Rewrite your story and interests.

Skills: Add or remove list items in the <ul> under Skills.

Social Links: Replace your LinkedIn, GitHub, and WhatsApp URLs.

CSS: Modify styles.css to match your favorite color palette.

Example:

“I am from Madhya Pradesh. I enjoy meeting new people and playing football.
I’m passionate about technology and currently pursuing CSE (Core) at SRMIST, Kattankulathur.”

🌍 Deploy on GitHub Pages

Push your code to a GitHub repository.

Go to Settings → Pages.

Under “Source,” select the main branch and click Save.

Wait a few minutes — your site will be live at:

https://<yourusername>.github.io/portfolio/
